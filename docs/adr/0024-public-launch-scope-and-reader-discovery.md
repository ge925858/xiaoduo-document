# 正式公开范围、共享草稿冲突与读者发现

Status: accepted

同一篇文章只有一份共享当前草稿。多个协作者同时编辑时使用修订号检测冲突，后保存的过期编辑必须进入版本对比，不允许静默覆盖。第一版不实现实时共同编辑，也不为每个协作者建立需要合并的私有草稿。

站主可以整站导出 Markdown 和元数据 JSON，数据库必须有自动备份；协作者不能批量导出全部内容。公开申请对同一邮箱和文章只保留一个待审核记录，并限制提交频率；站主可以拒绝申请或屏蔽邮箱。

读者侧发现能力包括全文搜索、RSS、站点地图和 Open Graph 分享卡片，不实现相关章节推荐。应用在写作台提供站内通知中心，用于申请、邀请和授权变化；第一版仍由站主复制邀请链接手动发送，不自动发送所有事务邮件。手机端完整支持阅读、搜索、申请、协作者登录和基础编辑，复杂版本对比与访问报表优先桌面端。

下一阶段明确暂缓多人独立空间、实时协作、评论点赞关注、通用团队文档与 Office 文件管理、AI 自动写作、知识图谱、自定义域名和商业化订阅。正式公开前必须完成真实数据库、HttpOnly Cookie 会话、服务端权限校验、OSS、自动备份、整站导出和基础访问统计。
