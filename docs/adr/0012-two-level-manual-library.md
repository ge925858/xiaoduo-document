# 第一版采用两层分类目录与手动排序

Status: accepted

第一版固定为“分类 → 章节”两层结构：分类不嵌套，章节是目录中的叶子节点，章节内部使用 Markdown 二级、三级标题形成页内小节。分类只保留名称、英文网址标识和章节顺序，不包含分类问题或分类说明。分类和章节都由作者手动排序，新建章节默认追加到当前分类末尾，目录不根据更新时间自动重排。分类创建、重命名和排序直接放在写作台目录中，不保留独立的复杂分类管理页面。

公开分类页只显示该分类下的公开章节，不承载长文。没有公开章节的分类不出现在公开笔记库。分类中存在任何笔记时禁止删除，作者必须先移动或删除这些笔记。未来若确有必要，可扩展为最多三层的分类树，但章节仍然只能是叶子节点。
