# 站主主导的文章级协作权限

Status: accepted; publication-permission portion superseded by ADR-0019

知笺保持一套公开知识库和一名站主，不转向多人知识库平台。站主独占发布、撤回、永久删除、分类管理和协作授权；协作者只能编辑被明确授权的文章。文章 ID 是权限的最小单位，写作台根据已授权文章反推出可见分类，未授权文章及分类不会出现在协作者的目录、搜索或统计中。协作者不能创建新文章，也不能看到协作申请入口。这个决定取代 ADR-0006、ADR-0007 中“只有一个登录身份、没有成员与权限体系”的边界。

未登录读者可以从公开章节末尾发起与该文章 ID 关联的协作申请，填写昵称、邮箱和申请备注；申请不会创建账号或密码。站主也可主动填写邮箱并选择一篇或多篇文章发出协作邀请。申请批准和主动邀请最终进入同一条邀请流程：系统生成绑定邮箱与文章授权的限时一次性链接，由站主通过邮件或即时通信手动发送；对方接受后设置密码并激活协作者账号，此后使用邮箱和密码登录，会话继续使用 HttpOnly Cookie。邀请链接过期只阻止尚未完成的首次激活，不影响已经激活账号的后续登录。

第一版不自动发送邀请邮件，站主复制邀请链接后自行发送。站主可以在协作者管理中即时增加或撤销文章授权；撤销授权后，协作者账号仍然存在，但对应文章立即从写作台消失且不能再读写。
