# 版本历史、线上对照与可逆撤回

Status: accepted; line-diff limitation superseded by ADR-0021

编辑器通过侧边抽屉展示版本历史，列表中包含当前草稿、手动保存版本和发布版本。历史版本可以查看完整内容、创建时间、可选说明和相对当前草稿的变化概况；第一版不做逐行差异。手动版本与发布版本长期保留，直到作者主动删除。

编辑器提供“当前草稿 / 线上版本”状态切换。分类名称、分类顺序和已发布章节顺序立即生效；章节标题、正文和所属分类必须更新发布后才影响公开页。撤回发布只关闭公开访问，不删除工作草稿、历史版本或发布记录。

只有当前草稿存在未发布修改时才提供对照入口；从未发布的新章节不显示线上版本。对照模式固定为左侧当前草稿可编辑、右侧线上版本只读，标题、分类和正文参与对照。差异按段落或内容块标出，两栏默认按相对位置联动滚动并允许关闭联动；移动端改为“当前草稿 / 线上版本”单栏切换。第一版只对照当前草稿与线上版本，手动历史版本先提供预览和恢复，不进入双栏对照。
