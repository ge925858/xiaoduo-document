# 产品定位为单人公开知识书与轻量文章协作

Status: accepted

知笺主要服务站主本人长期维护公开知识，以及少量受邀协作者编辑指定文章，不发展为每人拥有独立空间的多人笔记平台或开放作者社区。核心场景是按分类系统阅读、查证和持续维护结构完整的专题文章；私人速记、实时共同编辑、评论社区和通用团队文档不作为核心场景。

产品的差异化来自公开知识书式的阅读结构，以及文章级授权、共享版本日志和可追溯修改。知识图谱、双向链接和 AI 问答可以以后增强发现与整理，但不能替代内容、阅读和协作的基础价值。内容不锁定单一垂直领域，可以同时承载技术、人文、生活和其他长期知识，但应保持结构清楚、可持续修订。下一阶段优先补齐真实数据库、HttpOnly Cookie 会话、服务端权限校验、备份和对象存储，再扩展内容发现与协作通知。

产品按单人开发、低运维成本和少量基础设施预算推进。半年内的成功标准是站主能够持续写作、读者能够稳定阅读、受邀协作者能够完成真实修订；暂不以注册用户量、流量或收入作为首要目标。
