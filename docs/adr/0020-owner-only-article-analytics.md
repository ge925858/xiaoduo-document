# 站主专属文章访问统计

Status: accepted

公开文章页在作者与字数信息旁展示浏览量和具体更新时间，不公开访客 IP、独立访客或访问明细。浏览量按同一浏览器会话 30 分钟内访问同一篇文章只计算一次，并排除明确爬虫、预加载和后台请求；公开计数允许延迟 1–5 分钟更新。已登录站主的访问不纳入统计；已登录协作者访问公开文章时仍按普通读者计入，但协作者无权查看任何访问记录或报表。

服务端为每次有效公开访问保存文章、访问时间、完整访客来源 IP、IP 归属地和来源域名。IP 归属地由服务端地理库解析为省级或市级结果，只表示网络出口的大致位置，不用于推断访客真实住址或精确位置。来源域名只保留 `google.com`、`baidu.com` 或“直接访问”等主机级信息，不保存完整来源 URL、搜索词和查询参数。访客来源 IP 必须从可信反向代理链解析，不等同于官网服务器 IP，也不能直接相信任意客户端请求头。单次访问明细、完整 IP 和归属地只保留 30 天，之后删除；长期只保留浏览量与独立访客聚合数据。独立访客使用访客来源 IP 与浏览器信息生成每日不可逆哈希，不建立跨日设备身份；同一网络中的多个读者可能被合并，同一读者切换网络也可能被分开计算。

访问报表仅站主可见，协作者不能查询 IP、归属地、独立访客或访问明细。第一版报表提供总浏览量、独立访客、最近 7 天与 30 天趋势、文章浏览量排行、每篇文章最近访问时间和最近访问记录；最近访问记录明确展示文章、访客 IP、所在地、来源域名和访问时间。统计按 `Asia/Shanghai` 时区聚合。
