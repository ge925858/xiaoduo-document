# 公开贡献者署名与分阶段上线

Status: accepted

知识内容不限定单一垂直领域，产品体验保持对技术、人文、生活等长期知识的通用支持。公开文章顶部继续展示站主作者头像和名称，并在同一作者信息区展示实际贡献者；贡献者根据共享版本日志中真实保存或发布过该文章的用户自动汇总，仅获得授权但从未保存或发布的人不展示。

分类目录继续固定为两层，章节正文通过 H1–H5 组织内部层级。写作台通知中心第一版覆盖待审核申请、授权变化、邀请状态和协作者发布事件，不把阅读量变化制造成消息流。预览页当前不扩展最近更新或精选内容，后续单独调整。

正式上线按阶段推进：第一阶段完成真实公开阅读与站主写作，第二阶段开放文章级协作权限，第三阶段增强 RSS、SEO、站点地图和访问报表。首要成功指标是文章持续更新频率、真实阅读行为、回访读者，以及协作者实际完成的保存和发布修订。
