# 版本对比采用内容块差异与变更导航

Status: accepted

当前草稿与线上版本、历史版本与上一版本的对照共用一套 Markdown 差异模型。差异先按标题、段落、列表、待办、引用、代码块、表格和图片等内容块识别，相似内容块配对为“修改”，完全不同的内容才标记为删除或新增；修改块内部再标出具体新增和删除的文字。

对照顶部提供变化总数、新增/删除/修改统计、上一处和下一处按钮，以及可展开的变更列表。上一处和下一处只执行跳转，不自动打开列表；点击具体变化会同步滚动并高亮两侧内容块，在当前草稿对照中还会把光标定位并选中对应可编辑内容。差异完全由原始 Markdown 计算，不使用 AI 生成说明。
