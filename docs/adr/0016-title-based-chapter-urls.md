# 使用动态分级网址与章节标题路径

Status: accepted

公开网址固定为 `/library/{分类网址标识}/{章节标题路径片段}`。分类使用作者定义的英文标识，章节不使用单独 slug 字段，也不限定标题语言。章节路径直接来自作者填写的章节标题，不进行翻译或拼音化；“我是jack”保留为“我是jack”，“My Notes”也保留其英文文字，仅替换 URL 中不允许使用的字符。应用使用动态路由匹配路径，并在保存的分类与章节数据中查找内容；不需要在代码中预先声明每一篇文章。

章节在首次保存时可以生成内部路径，只有发布后才允许读者访问。已发布章节修改标题或分类时生成新路径，并保留旧地址到新地址的自动重定向。相同分类内的重名章节追加数字后缀，不同分类允许标题重复。

前端只维护一条章节页面路由规则，由 URL 参数选择实际章节。发布接口负责更新数据、生成新地址和刷新相关缓存；新章节发布后必须立即可以访问，不等待整站重新构建。动态路由未找到已发布章节时返回 404。
