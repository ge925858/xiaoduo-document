# 草稿自动保存，版本快照手动创建

Status: accepted

每个章节维护一个当前工作草稿和若干历史版本。编辑停止约 800ms 后自动保存当前草稿，`Ctrl/Cmd + S` 立即保存当前草稿，但两者都不生成历史版本。历史版本只在作者点击“保存版本”时手动创建，并允许附加一句可选说明；发布或更新发布时额外生成不可变的发布版本，用于明确线上内容基准。

历史列表只显示手动版本和发布版本，当前工作草稿单独显示为“未发布修改”。恢复历史版本时先恢复到工作草稿，作者确认后再更新发布，不直接替换公开内容。站内跳转先尝试完成保存；关闭、刷新页面仍有未完成保存或保存失败时，应用需要阻止离开并提示重试。
