# 知笺原型

一个单人作者的公开知识网站与私人写作后台，使用本地模拟数据验证产品结构。当前版本尚未接入真实数据库、服务端鉴权和阿里云 OSS。

## 启动

```powershell
npm install
npm run dev
```

默认访问 `http://localhost:4173`。

## 公开站

- 预览页：说明网站内容，并提供“进入笔记库”入口
- 笔记库：固定左侧目录，按“分类 → 章节”两层组织内容
- 分类页：只展示该分类下已经公开的章节
- 章节页：Markdown 正文、标题、作者头像与昵称、字数和具体更新时间、页内目录和上一篇/下一篇
- 章节网址：`/library/{分类英文 slug}/{标题路径}`，首次发布后修改地址会保留旧地址重定向
- 搜索：按章节标题和正文检索
- 公开章节展示字数和浏览量，并保留具体更新时间
- 公开站不展示写作台入口，站主和协作者通过直接网址或邀请进入
- 浅色、深色主题与移动端布局

## 写作台

访问 `/studio`。

原型密码：`zhijian`

已覆盖：

- 单人密码登录
- 个人资料编辑：昵称和本地头像上传
- 草稿、公开章节、发布时间和站点资料管理
- 分类创建、编辑、排序；分类下只要还有章节就禁止删除
- 章节上移、下移与分类内排序
- Tiptap 所见即所得 Markdown 编辑、斜杠菜单和图片插入
- 内容块拖动按钮支持正文、H1–H5、列表、待办、引用与代码块互相转换
- 支持下划线、文字颜色和背景高亮，并保留到公开 Markdown 页面
- Markdown 文件导入、纯 Markdown 粘贴
- 停止输入约 800ms 自动保存草稿，`Ctrl/Cmd+S` 立即保存
- 手动保存历史版本，并可恢复到当前草稿
- 发布时生成不可变发布版本，支持更新发布和撤回公开访问
- 编辑页与公开页共用文章排版
- 非对照模式显示当前草稿目录，可点击跳转到对应小标题
- 有线上版本时支持左侧草稿、右侧线上版本的对照模式
- 对照模式默认联动滚动，可关闭；移动端使用标签切换
- 回收站按操作者区分，协作者只看到自己移入的内容，站主可查看全部；保留 30 天，恢复后需要重新发布
- 写作台支持按分类和状态筛选文章
- 站主专属访问报表展示浏览量、独立访客、趋势、文章排行、完整访客 IP 和粗略所在地
- 未登录读者可从章节末尾提交与当前文章关联的协作申请
- 站主可在协作管理中审核申请、主动邀请、复制一次性邀请链接和管理文章授权
- 协作者通过邮箱与密码登录，只能看到并编辑被授权的文章
- 协作者不能创建文章、管理分类、撤回或永久删除内容，但可以发布和更新获授权文章
- 手动版本与发布版本进入共享日志，记录版本作者并支持与上一版本对照
- 版本作者同时展示用户昵称和站主/协作者角色
- 版本对照提供内容块级变更列表、行内新增/删除高亮和上一处/下一处快速跳转
